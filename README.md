SRT 轉 TXT 進階轉換器 (SRT to TXT Converter)
這是一個基於 Python (Tkinter) 開發的圖形化介面工具，專門用於將 .srt 字幕檔轉換為純文字 .txt 檔。它具備智慧分檔、時間軸格式化以及段落合併功能，非常適合整理訪談逐字稿、會議記錄或影片字幕。

🌟 主要功能
圖形化操作介面 (GUI)：免打指令，直觀易用。

批次/單檔處理：支援單一檔案轉換，或指定資料夾批次轉換所有 .srt 檔。

自動長檔分割：可設定超過指定時數（如 2小時、3小時...）自動將檔案切分為 檔名-1.txt, 檔名-2.txt。

智慧文字合併：可設定「每 N 秒」合併一段文字，方便閱讀長篇內容。

時間軸保留：支援輸出 [開始時間~結束時間] 格式的時間標記。

自動取代：若輸出檔名重複，程式會自動覆蓋舊檔。

💻 系統需求
作業系統：Windows / macOS / Linux

程式語言：Python 3.6 或以上版本

相依套件：無須安裝額外套件 (使用 Python 內建標準庫 tkinter, os, re)

🚀 安裝與執行
確保電腦已安裝 Python。

下載本工具原始碼 (例如 srt_converter.py)。

在終端機或命令提示字元 (CMD) 中執行：

Bash

python srt_converter.py
📖 操作指南
介面分為五個主要區塊，請依序設定：

1. 選擇來源模式
單一檔案 (.srt)：僅處理一個特定的字幕檔。

指定資料夾 (批次處理)：自動搜尋該資料夾內所有 .srt 檔案進行轉換。

2. 設定路徑
來源位置：選擇 .srt 檔案或資料夾路徑。

存檔位置：轉換後的 .txt 檔案存放位置（若未設定，預設與來源相同）。

3. 檔案分割設定
若您的錄音/影片時間非常長（例如 5 小時），可啟用此功能。

啟用長檔案自動分割：勾選後，後方輸入框解鎖。

設定時數：輸入數字（整數）。

範例：設定 3 小時。若檔案長度為 5 小時，將產生：

檔名-1.txt (包含 0~3 小時內容)

檔名-2.txt (包含 3~5 小時內容)

4. 內容格式設定 (核心功能)
決定產出的 TXT 內文長什麼樣子。

顯示時間軸：

勾選後，每段文字前會加上 [HH:MM:SS~HH:MM:SS]。

若不勾選，僅保留純文字。

啟用固定時間合併：

不勾選：依據 SRT 原始斷句換行。

勾選並設定秒數 (例如 60 秒)：程式會將每 1 分鐘內的字幕合併為同一段落。

5. 開始轉換
點擊按鈕，下方日誌 (Log) 視窗將顯示處理進度與產出的檔案名稱。

📝 輸出範例對照
假設原始 SRT 內容如下：

程式碼片段

1
00:00:05,000 --> 00:00:08,000
大家好

2
00:00:08,500 --> 00:00:12,000
歡迎來到今天的專訪
模式 A：原始逐行 + 保留時間軸
設定：勾選「顯示時間軸」，不勾選「合併」

輸出結果 (.txt)：

Plaintext

[00:00:05~00:00:08] 大家好
[00:00:08~00:00:12] 歡迎來到今天的專訪
模式 B：合併段落 (每 60 秒) + 保留時間軸
設定：勾選「顯示時間軸」，勾選「合併」，設定 60 秒

輸出結果 (.txt)：

Plaintext

[00:00:00~00:01:00]
大家好 歡迎來到今天的專訪 (此處會合併該分鐘內所有文字...)
模式 C：純文字閱讀
設定：不勾選「顯示時間軸」，勾選「合併」

輸出結果 (.txt)：

Plaintext

大家好 歡迎來到今天的專訪...
⚠️ 注意事項
編碼問題：程式優先使用 UTF-8 讀取，若失敗會嘗試 CP950 (繁體中文 Big5)，通常可解決大部分亂碼問題。

檔名重複：輸出資料夾若已有同名 .txt 檔案，程式會直接覆蓋不另行通知，請留意。

時間計算：分割檔案是以 SRT 的「開始時間碼」為基準進行切分。
